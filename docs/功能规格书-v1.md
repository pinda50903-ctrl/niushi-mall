# 牛视商城 重实现功能规格书 v1

> 本文档为 clean-room 规格提取产物：仅描述系统**功能**（做什么），不包含任何原项目代码、注释、命名的复制。
> 用途：作为全新独立实现的唯一依据，同时作为独立创作的过程证据。
> 原项目完整文件清单位于 `docs/inventory/`（仅作功能范围核对用，实现阶段不得逐文件对照原代码）。

## 1. 系统概述

多租户（SaaS）电商系统，基于 Yii2 框架（PHP），包含四个面：

| 面 | 说明 |
|---|---|
| 平台总部后台 | 平台运营方使用：租户（商城）管理、平台账号与权限、插件管理、云服务配置 |
| 商城管理端 | 每个租户的商家后台：商品/订单/用户/营销/装修/统计/设置 |
| 用户端 API | 面向 C 端用户的 HTTP API：浏览/下单/支付/会员中心/售后 |
| 多端触达 | 微信小程序、百度小程序、支付宝小程序、抖音小程序、H5、公众号 |

## 3. 功能域清单

### 3.1 平台总部（admin）
- 账号体系：超级管理员 / 普通管理员 / 权限组 / 子账号权限分配 / 登录审计
- 租户管理：商城列表、开通/禁用/过期、租户数据统计
- 插件管理：插件列表、分类、安装/同步
- 云服务：云配置、版本管理
- 系统设置：附件存储、缓存、队列配置

### 3.2 商城管理端（mall）
- 商品：SPU/SKU、分类、品牌、规格、库存、上下架
- 交易：订单列表/详情、发货、售后/退款、评价
- 用户：会员列表、等级、标签、储值/积分余额
- 营销：优惠券、满减、营销活动入口
- 页面装修：首页 DIY 拖拽布局、导航、广告位、弹窗
- 统计：销售/用户/商品多维报表
- 设置：支付方式、物流、小程序配置、消息通知、打印
- 插件：插件菜单挂载、插件内管理页

### 3.3 用户端（api）
- 首页/分类/商品详情/搜索
- 购物车、下单、支付回调、订单管理
- 会员中心：资料、余额、积分、优惠券、收藏/足迹
- 售后申请/进度
- 分销关系、推广海报（视插件启用）

### 3.4 核心服务（core）
- 支付聚合：微信支付/支付宝、统一下单与回调、退款
- 微信生态：公众号/小程序 access token、模板消息、素材、JSSDK
- 短信：多通道短信发送
- 物流：快递单查询、电子面单
- 云能力：云存储、云市场/版本校验（重实现时可替换为本地实现）
- 队列：异步任务（订单处理、消息推送等）
- 货币/积分/佣金结算
- 事件处理器体系：订单/商品/用户生命周期钩子

### 3.5 插件矩阵（50 个，按类分组）

**交易营销类**：拼团、秒杀、限时闪购、砍价、预售、每周购、批发、组合装、赠品、兑换中心、红包、 lottery 抽奖、刮刮卡、砸蛋福袋
**分销会员类**：分销裂变、股东分红、分红 bonus、积分商城、会员卡、签到、步数、SCRM、社区团购
**商户类**：多商户 mch、收银员 teller、店员 clerk、核销、自提、扫码支付、微信小商店
**多端适配类**：微信、H5 mobile、微信小程序、百度小程序、支付宝小程序、抖音小程序、应用管理
**内容工具类**：DIY 装修、预约、表单商品、电子卡、客服、快速分享、网址跳转、区域代理、点起来、助手、其他

> ⚠️ 实际生产站通常只启用其中少数插件。**请确认你生产环境实际使用的插件清单**，据此划分 P0/P1/P2 优先级，避免为不用的插件支付重写成本。

## 5. 重实现技术方案（建议）

| 项 | 新方案 |
|---|---|
| 后端 | Yii2 + PHP 8.1+，模块化分层（api/admin/mall 三模块 + domain 服务层 + repositories），全新目录结构 |
| 管理端前端 | Vue3 + Element Plus（全新视觉风格），重做全部页面 |
| 用户端前端 | uni-app（Vue3），一套代码出 微信小程序 + H5（+百度/支付宝/抖音按需） |
| 数据库 | 全新 schema 设计，MySQL 8 |
| 队列/缓存 | Redis + Yii queue |
| 鉴权 | JWT（用户端）+ Session/RBAC（管理端），全新实现 |
